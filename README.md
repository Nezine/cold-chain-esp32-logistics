# Cold Chain Logistics Project

## Team Roles

1. Lead: coordination, scope, decisions, and integration tracking.
2. Domain and Backend: domain model, business rules, persistence design, and service boundaries.
3. Frontend: user workflows, monitoring screens, dispatch screens, and alert presentation.
4. IoT Simulation: simulated sensor streams, shipment conditions, and temperature events.
5. QA and Documentation: acceptance criteria, test planning, traceability, and final documentation.

## Working Order

1. Complete the discovery exercises together.
2. Agree on the shared requirements before individual implementation work.
3. Review the domain model before designing interfaces between roles.
4. Build and review each slice in small increments.
5. Run the shared testing exercises before preparing the final presentation.

## Folder Rules

- Put personal working notes in the role folder.
- Put agreed artifacts in the matching shared folder.
- Record unresolved decisions in shared/meeting-notes.
- Do not treat an individual draft as an agreed team decision until reviewed.
