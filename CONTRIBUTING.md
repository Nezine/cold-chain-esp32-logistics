# How We Work Together

This is a learning project. You do not need to be an expert programmer to contribute.

## Before You Start

1. Read `README.md`.
2. Read the exercise file for your role.
3. Check the latest notes in `shared/meeting-notes/`.
4. Ask before changing an agreed rule or shared file.

## Where Work Goes

- Personal notes go in your numbered role folder.
- Decisions agreed by the whole team go in `shared/`.
- Application code goes in the project code folder once the team chooses the technology.
- Test results go in `shared/testing/`.

## Small Work Cycle

1. Choose one exercise or small task.
2. Tell the team what you are working on.
3. Make the smallest useful change.
4. Ask another member to review it.
5. Test or explain how it was checked.
6. Commit with a clear message.

## Commit Message Examples

- `docs: agree temperature rules`
- `feat: show critical shipment alert`
- `test: check warning threshold`
- `docs: record demo limitations`

Do not commit passwords, API keys, private data, or local configuration files.
